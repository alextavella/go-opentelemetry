# Observability | Go Opentelemetry

Este projeto fornece ferramentas e exemplos para implementar observabilidade em aplicações Go.

## Instalação

1. Certifique-se de ter o Go instalado em sua máquina.
2. Clone este repositório:
   ```bash
   git clone https://github.com/alextavella/go-opentelemetry.git
   ```
3. Navegue até o diretório do projeto:
   ```bash
   cd go-opentelemetry
   ```
4. Instale as dependências:
   ```bash
   go mod tidy
   ```

## Uso

1. Execute o projeto:
   ```bash
   go run cmd/api/main.go
   ```
2. Acesse os endpoints de monitoramento e métricas fornecidos.
